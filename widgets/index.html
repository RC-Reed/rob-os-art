Notion widgets

Small animated embeds for Notion pages. Each one is a single HTML file with no outside scripts, fonts or tracking. You set everything in the link, and nothing is stored.

How to add one

  1. Copy a link below and change the values after ? to suit.
  2. In Notion, type /embed, paste the link and press Embed link.
  3. Drag the embed's edges to size it. They look best between about 300×120 and 600×300.

Options that work on every widget

theme=light
Light colours, for light Notion pages.
bg=none
Transparent background so the widget sits on the page. Pair with theme=light on light pages.
accent=teal
Accent colour: gold, amber, teal, blue, green, red, purple, white, or a hex value such as accent=4dbfb3.
motion=off
No animation. Also automatic when the device asks for reduced motion.
