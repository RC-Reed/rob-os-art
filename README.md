# rob-os-art

Artwork for a personal Notion workspace: "Nightwatch" covers (1500x600) and gold line icons (256x256).
Generated from code. No personal data. Public only so Notion can load the images by URL.

`widgets/` holds small animated Notion embeds (countdown, clock, progress, year progress). Each is one HTML file with no outside scripts, fonts or tracking; everything is set in the URL. Open `widgets/index.html` for example links.
